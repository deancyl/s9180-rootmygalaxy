## 变更内容

### B2：renice 口径显式化（模块侧，6 文件 +39/-11）
- **口径真相**：终验 `app_renice=192` vs `changed_3rd_party=618` 曾被疑为计数矛盾，实为单位差异——app_renice 是进程数，还原清单是线程（tid）级。192 进程 × ~19 线程 ≈ 3646 tid = ok 2614 + chg 618 + skip 514，账目吻合。
- 新增 `reniced_tid` 计数器（renice_tree 成功时累加，窗口开始清零），storm_end 输出，与还原统计（tid 口径）对账；
- restore 统计行新增 `unit=tid` 标注；
- 还原前快照明细至 `run/renice_detail_last.log`（tid 原nice 目标nice 包名，run/ 为 700 root 私有目录），供 v1.5.0 打击面分析。

### B1：效果度量可信化（采集器 mt_stormcap.sh v3）
- launcher gfxinfo 从单轮改 3 轮（间隔 60s）——终验 82 帧小样本教训：重启后累计帧数随时间增长，单轮百分位统计不可信；
- am_kill/am_anr 从纯计数增加明细行（tail10），支撑异常归因。
