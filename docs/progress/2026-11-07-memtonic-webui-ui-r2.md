## 变更内容（详见 CHANGELOG 11-07 条目）

1. **UI-R1 信息架构**：告警按严重度拆成独立卡片（原始 `key=value` 收进折叠，最多直显 2 条）；`fmtSnapshot()` 把 incident 原始文件名解析成「时间 / 类型 / 原因」三列；14 张计数卡瘦身为「数字 + 标题 + 状态」并默认折叠；`rb_enabling > 0` 置顶红色「禁止重启」条；危险操作收进折叠、刷新常驻；小字对比度从 ≈2.6:1 提升到 ≈5.6:1；修正刻度图例的 CSS 冲突。
2. **UI-R2 状态行**：`v1.13.13 / vc53 · 主✓ 风暴✓ CPU✓ 护盾✓ 4/4 · root 正常` 挤成一行的小字，改为三个状态胶囊「保护 4/4 / 权限 正常 / 版本 v1.13.13」；四守护徽章明细、pid、vc 值收进隐藏数据源，由 ⓘ 弹层动态读取展示。
3. **UI-R2 ⓘ 信息层**：新增通用弹层与 `INFO_DEFS` 25 条说明，PSI / Java 堆 / trim / GC / staged rollback / HAL tombstone / FR-RN1 / majflt / RSS / versionCode / KernelSU 等术语全部集中于此，主界面零术语。
4. **UI-R2 全站白话化**：副标题一句话说清模块作用；指标、刻度、水位判定、14 类计数名、告警标题与动作、折叠标题、4 个按钮名称全部改成人话；每个操作按钮配一行「这会做什么」+ ⓘ；确认弹窗主文案白话、技术细节单列。
5. **底层语义核对**：四守护命名对齐真实脚本名；FR-RN1 描述由易误导的「眼镜语音保护」更正为「眼镜相关治理：后台渲染 / 池线程温和降权 + 语音链路削峰豁免」；按钮说明与真实命令逐条对齐。
